# Projeto-Sonora
Este é o Sonora, uma plataforma de streaming de músicas (pense num Spotify bem enxuto,
sem a parte bonita, só o motor por baixo). O sonora é um projeto da faculdade escrito em Java, que vai crescendo conforme os conteúdos que vão ser ensinados até chegar em seu modelo final. Cada pasta deste repositório vai ser uma nova versão, então, vai ser possível vizualizar a evolução do projeto :).
